# Portfolio

Modern portfolio website with interactive effects.

## Deploy

**Vercel**: Upload to vercel.com, buy .dev domain in settings

**Netlify**: Upload to netlify.com, add domain in settings

**Manual**: Run `npm run build`, upload `dist/` folder

## Setup

```bash
npm install
npm run dev
npm run build
```
